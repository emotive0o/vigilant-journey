# Simple Calculator

A lightweight calculator built using HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal support
- Clear, backspace, and sign toggle
- Keyboard support for quick input
- Responsive, browser-based interface

## Files
- `index.html` – page structure
- `style.css` – layout and styling
- `script.js` – calculator logic and keyboard support

## Run It
Open `index.html` in any modern browser.

## Notes
This project is intentionally simple and can be extended with features like percentages, memory buttons, or scientific functions.
